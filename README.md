# Vandotec-website

Herbouw van [vandotec.be](https://www.vandotec.be) (installatiebedrijf: tankstations, EV-laadinfrastructuur, infrastructuurwerken) als statische Astro-site. Privé-repo, Nederlands, solo-onderhouden met AI-assistentie.

- Bouwen: `npm run build` · Bekijken: `npx astro preview` · SEO: `node tasks/check-seo.cjs`
- Spelregels voor mens én AI: zie `AGENTS.md` (enig contract).
- Stand van zaken: zie `.planning/STATE.md`.
- Staging: `new.powerland.be` achter Cloudflare Access — instructies in `tasks/staging-upload.md`.
