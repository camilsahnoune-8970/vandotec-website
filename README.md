# Vandotec-website

Herbouw van [vandotec.be](https://www.vandotec.be) (installatiebedrijf: tankstations, EV-laadinfrastructuur, infrastructuurwerken) als statische Astro-site. Publieke repo (sinds 2026-10-05), Nederlands, solo-onderhouden met AI-assistentie.

- Bouwen: `npm run build` · Bekijken: `npx astro preview` · SEO: `node tasks/check-seo.cjs`
- Spelregels voor mens én AI: zie `AGENTS.md` (enig contract).
- Stand van zaken: zie `.planning/STATE.md`.
- Staging is geschrapt uit de planning (besluit Camil 2026-10-07); `tasks/staging-upload.md` en `.github/workflows/deploy.yml` zijn oud en alleen handmatig. Niets live zetten zonder "ja" van Camil.
