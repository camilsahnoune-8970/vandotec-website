# SPEC-template (Nederlands, verplicht voor alles boven een kleine fix)

Kopieer dit bestand naar `specs/<onderwerp>.md`, vul in, en laat Camil het goedkeuren
vóór er code geschreven wordt. Geen goedgekeurde spec = geen PR.

## 1. Doel (één zin)

Wat is er klaar als dit af is?

## 2. Context

Waarom nu? Verwijzing naar `STATE.md`-regel, issue of eerdere PR.

## 3. Scope

- Wél: …
- Uitdrukkelijk níet: …

## 4. Acceptatiecriteria (meetbaar, afvinkbaar)

- [ ] …
- [ ] … (cijfers waar mogelijk: build groen, SEO-score, KB-budget, aantallen)

## 5. Verificatie

Welke commando’s/checks bewijzen dat het werkt? (bv. `npm run build`,
`node tasks/check-seo.cjs`, screenshot 1440/390, renderproof)

## 6. Smaak-check

- [ ] Nodig (zichtbare wijziging → screenshots ter beoordeling aan Camil)
- [ ] Niet nodig (onzichtbaar: techniek, tekstfix, tooling)

## 7. Vrijstelling?

Alleen voor kleine fixes (typo, één regel CSS, één woord tekst): schrijf hier
waarom geen volledige spec nodig is. Bij twijfel: wél een spec.
